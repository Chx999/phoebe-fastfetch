# Phoebe Fastfetch

Display random images from [Phoebe Hub](https://phoebehub.top/) alongside Fastfetch system information.

## Status

The Python implementation is under development. The initial repository structure and CLI entry point are ready.

## Development

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -e .
ff --help
```
